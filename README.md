# The Shy Button

A button that would rather not be clicked. It runs away from your pointer, makes excuses, blushes, and after 10 escapes gets tired and lets you catch it. Works with mouse, touch and keyboard.

Assignment 1 – Useless Web (Part 3: Final Product)

## Structure
```
index.html
css/style.css
js/script.js
```

## Run locally
Open `index.html` in a browser. No build step or dependencies.

## Deploy (GitHub Pages)
1. Create a new public GitHub repo and upload these files with `index.html` at the repo root.
2. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`. Submit that URL.
